## 版本与验证

首发保留 0.1.0；首发记录不安排版本提升。以后每个行为变更新增 Changeset，执行 `npm run version:packages` 统一生成单包版本与 changelog。

```bash
npm ci --ignore-scripts
npm run release:check
npm run verify:install
npm view dsh-plugin-workbench-suite name version --json
```

预检通过后，记录代码提交并确认发布账号和目标，再运行 `npm run release:publish`。GitHub Actions 仅构建、测试和打包预检，不自动发布。本次合并不执行 npm publish、push 或远端创建。

发布包包含运行代码、浏览器构建文件、说明和许可证；不包含开发依赖、测试、过程记录、.env 或用户账号数据。
