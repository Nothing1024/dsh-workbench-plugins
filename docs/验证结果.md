## 包结构与入口

- 仓库根目录是唯一 npm 包，没有 workspaces 或内部 peer 依赖。
- 源码分别位于 src/sources、src/herdr、src/grok；来源栏共享接口只在包内部使用。
- index.js 是唯一宿主入口，dist/client.js 注册唯一浏览器插件 factory。
- cordis.patch.yml 只启用一个工作台插件。

## Grok 设置与状态的浏览器回放

使用临时本机服务、真实 React 页面和模拟机器人数据，实际点击账号与会话设置、输入 Auth、保存、重新启动服务并移除配置。输入框保存后为空且保持密码样式；Auth 不出现在读取接口或浏览器 localStorage 中；无效输入保留并显示错误，未授权写入返回 401。
